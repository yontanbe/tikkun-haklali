# תיקון הכללי

אפליקציית PWA לאמירת תיקון הכללי של רבי נחמן מברסלב, נוסח עדות המזרח.

- עשרת המזמורים: טז, לב, מא, מב, נט, עז, צ, קה, קלז, קנ
- הריני מקשר עצמי ולשם יחוד לפני האמירה
- פסוקי מי יתן מציון, תפילה קצרה ותפילת רבי נתן מליקוטי תפילות בסיום
- מצב מזמור מזמור או רצף, ניקוד, גודל אותיות, שלוש ערכות צבע, מסך דולק
- ספירת תיקונים ורצף ימים, נשמר מקומית בלבד
- עובד אופליין (service worker)

טקסטים: Sefaria (תהילים לפי כתר ארם צובה, תיקון הכללי מהדורת rabenubook, CC-BY-SA). עיצוב ודמויות: Gemini.

GitHub Pages: הקובץ `index.html` בשורש, branch main.
